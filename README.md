## HistoGPT-LV — for classifying BCC vs cSCC

This repo fine-tunes [HistoGPT](https://github.com/marrlab/HistoGPT). you can run offline on `.h5` feature files with [the fine‑tuned model](https://drive.google.com/file/d/136LGjBabMBJ0Q3mMuEtv_ZIPQiisDSBU/view?usp=drive_link).

### `run_best_model`
- Loads the [`.pth`](https://drive.google.com/file/d/136LGjBabMBJ0Q3mMuEtv_ZIPQiisDSBU/view?usp=drive_link), reconstructs `CancerClassifier` from `architecture_config`, wraps it in an `InferenceModel` that disables training features and sets eval.
- Loads one `.h5` file, optionally limits patches (for memory), converts features to bfloat16, and runs a forward pass under autocast.
- Produces logits → softmax probabilities → predicted class and human-readable diagnosis, with confidence.

Run inference on one slide:

```bash
python run_best_model.py \
  --model histogpt-bcc_cscc.pth \
  --h5_file /path/to/slide_features.h5 \
  --max_patches 1000 \
  --device auto \
  --output_file inference_result.json
```

### Notes on fine-tuning
- **Data**: Precomputed patch features per slide are stored as `.h5` with datasets `features` and `coordinates`. Labels are inferred from filename tokens:
  - `sbbc`, `ibcc` → basal cell carcinoma (class 0)
  - `pek` → squamous cell carcinoma (class 1)
- **Model** (`models/aggregator.py`): `CancerClassifier(d_input=1024, d_model=1536, num_cls=2)`
  - NaViT position embedding → FlashPerceiver backbone → RMSNorm → gated attention (learns what/how much) → linear classifier
- **Pretrained init**: `finetune/utils/pretrained_loader.py` loads HistoGPT aggregator weights offline, transferring backbone weights (head stays random).
- **Training loop**: `finetune/train_mil_classifier.py`
  - Stratified K-fold CV with `MILDataset` and custom collate
  - BF16 mixed precision, gradient clipping, AdamW + warmup + cosine decay
  - Metrics via TorchMetrics; checkpoint monitors `val_auroc`; early stopping on AUROC
  - After each fold: reload best checkpoint and validate; after CV: compute summary and copy the best fold’s checkpoint dir to `results/best_model`

Run training (offline; requires local files):

```bash
python finetune/train_mil_classifier.py \
  --feat_path /path/to/h5_dir \
  --histogpt_weights /path/to/histogpt_pretrained.pth \
  --biogpt_path /path/to/local/microsoft_biogpt-large \
  --k_folds 5 --max_epochs 50 --max_lr 5e-5 \
  --batch_size 1 --max_patches_per_slide 1000 \
  --output_dir ./results
```

#### Export the best checkpoint to an inference-ready `.pth`
Pick the best `.ckpt` inside `./checkpoints/fold_X/` (or the one copied to `./results/best_model/`) and export:

```bash
python -m finetune.utils.export_inference_model \
  --checkpoint ./checkpoints/fold_1/fold_1_best_epoch=E_val_auroc=A.ckpt \
  --histogpt_weights /path/to/histogpt_pretrained.pth \
  --biogpt_path /path/to/local/microsoft_biogpt-large \
  --output histogpt-bcc_cscc.pth
```

## Project description

### Methods
The project included 251 slides of 240 BCC patients and 84 histology slides of 75 SCC patients from the University Hospital of Erlangen. The task is to output BCC or cSCC classification from image inputs. Before fine-tuning, zero-shot inference using the pre-trained model was performed to assess the baseline performance.
The fine-tuning was achieved with the following specifications:

1. Model architecture
  We implemented a multiple instance learning (MIL) classifier, CancerClassifier, based on an attention-aggregator framework. Input features consisted of patch embeddings of dimension 1024 and corresponding 3D spatial coordinates. Binary classification targeted basal cell carcinoma (0) and squamous cell carcinoma (1).

  Patch-level features were first augmented with positional embeddings generated by NaViTEmbedding (d_model=1024, max_len=1024, patch_size=512). The backbone was a FlashPerceiver with 6 layers, 16 attention heads, 1536-dimensional latent representations, and 640 latent tokens. Latents were concatenated before passing through gated attention MIL pooling, followed by normalization via FusedRMSNorm (eps=1e-5). The final classification head was a linear layer mapping the 1536-dimensional latent representation to the two output classes.

2. Data preparation
  Whole-slide image (WSI) features were stored in HDF5 files, with datasets features (N × 1024) and coordinates (N × 3). Slide-level labels were inferred from filename tokens (sbbc or ibcc: basal cell carcinoma, pek: squamous cell carcinoma) as defined in finetune/datasets/datasets.py. To balance computational efficiency and memory, we limited the number of patches per slide to 1000 during training and inference. Dataloaders used a collate function that converted tensors to lists compatible with the MIL aggregator, with a typical batch size of one slide per iteration.

3. Pretraining
  Backbone weights were initialized from a pretrained HistoGPT aggregator. Only the backbone parameters were transferred; the classification head was randomly initialized. Pretrained weights and local BioGPT model files (config.json, pytorch_model.bin, tokenizer_config.json) were loaded offline to ensure reproducibility.

4. Training and evaluation
  Training was performed using finetune/train_mil_classifier.py. Stratified K-fold cross-validation (k=5 by default) was applied to mitigate dataset imbalance. Optimization used AdamW with warmup and cosine learning rate scheduling via LambdaLR. Hyperparameters included betas=(0.9, 0.95), weight decay=0.05, start_lr=0.0, peak_lr=5e-5, and final_lr=1e-6. Training used bf16-mixed precision on a single GPU, with gradient accumulation over 16 batches, batch size 1, and gradient clipping of 1.0. Data loaders were configured with 4 workers and pinned memory.
  Model performance was evaluated on validation splits using AUROC as the primary metric, along with macro F1, balanced accuracy, and standard classification metrics (accuracy, precision, recall) computed per class. Early stopping monitored val_auroc with a patience of 10 epochs and a minimum delta of 0.001. The checkpoint with the highest validation AUROC was retained for each fold, and the fold with the best AUROC was selected as the final model for downstream use.
